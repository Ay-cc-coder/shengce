# 录音监控 / AudioWatch

## 一句话

选一个 iPhone 文件夹，用 HTTPS WebDAV 验证连接，把已有和新出现的文件按原文件名静默上传；网络不可用时保留队列，恢复后自动继续。

## 使用者与场景

- 使用者：在自己的 RootHide iPhone 上保存通话录音、语音备忘录或其他音频，并有一台可写入的 WebDAV 服务器。
- 场景：录音不会自动同步，手动导出麻烦；或者需要把录音持续归档到 NAS / 私有云。
- 关键约束：文件不能改名；断网不能丢队列；空闲时不能持续轮询文件夹；开始前必须验证 WebDAV 地址、账号和写入权限。

## 需求映射

| 需求 | 实现 |
| --- | --- |
| 安装后桌面显示 App 图标 | `AudioWatch.app` + 全部尺寸图标，`postinst` 调用 `uicache` |
| UI 选择监控文件夹 | 自定义文件夹浏览器，支持快捷位置、上一级、手动输入路径 |
| 新文件才上传，空闲不占资源 | 每个子目录一个 vnode 事件源；无文件事件时不扫描、不轮询 |
| 网络失败标记并等待 | 持久队列 + `SCNetworkReachability` + 指数退避；状态显示“等待网络” |
| 原本已有文件先上传 | 启动时递归扫描，发现后按顺序入队；完成后保持静默 |
| 文件名不修改 | WebDAV PUT 路径使用原始文件名；子目录结构原样保留 |
| WebDAV 地址/账号/密码测试 | `PROPFIND` 验证地址与认证，再 PUT/DELETE 探针验证写入；通过后才允许开始 |
| UI 设计流程 | 采用 `fe-design` / `ux-max` / `taste` / `polish` 的 Operate 场景规范 |

## 非目标

- 不提供云端账号，不绑定任何特定 WebDAV 服务商。
- 不转码、不切片、不重命名、不读取音频内容。
- 不删除本地文件；服务器已有同名文件时由 WebDAV 覆盖。
- 不代理远程文件浏览；UI 只管理本机监控与上传状态。

## 成功标准

1. 安装后能在桌面看到“录音监控”图标并启动。
2. 首次使用必须通过 WebDAV 测试才能开始。
3. 已有文件先上传，新文件随后自动上传；服务器文件名与本地一致。
4. 关闭 App 后守护进程继续工作；空闲时没有轮询。
5. 断网时文件显示为等待网络，网络恢复后自动上传。
6. 浅色/深色、iPhone 竖屏与横屏均可读、可操作。
